# Modern Music Player

A beautiful and responsive music player web application with multi-language support and dark mode.

## Features

- 🎵 Modern and responsive UI
- 🌓 Dark mode support
- 🌐 Multi-language support (English, Persian, Pashto)
- 📱 Mobile-friendly design
- 🎨 Beautiful animations and transitions
- 🔍 Search functionality
- 📋 Playlist management
- 🔊 Volume control
- 🎯 Progress bar with seek functionality

## Technologies Used

- HTML5
- Tailwind CSS
- jQuery
- Font Awesome Icons

## Getting Started

1. Clone this repository
2. Open `index.html` in your web browser
3. Start enjoying your music!

## Language Support

The music player supports the following languages:
- English (default)
- Persian (فارسی)
- Pashto (پښتو)

To change the language, use the language selector in the top-right corner of the player.

## Dark Mode

Toggle dark mode by clicking the moon/sun icon in the top-right corner. Your preference will be saved for future visits.
